# AdGuard VPN GUI for Linux

Легковесный графический интерфейс (GUI) для официального [AdGuard VPN CLI](https://github.com/AdGuardTeam/AdGuardVPNCLI) на Linux.

Официальный клиент AdGuard VPN для Linux работает только через командную строку. Этот проект решает эту проблему, предоставляя удобный визуальный интерфейс для управления подключениями, выбора локаций и просмотра статуса.

##  Возможности

*   **Управление в один клик:** Подключение и отключение VPN без ввода команд.
*   **Список локаций:** Автоматическая загрузка доступных серверов с отображением ping (задержки).
*   **Статус в реальном времени:** Мгновенное отображение текущего состояния (Connected/Disconnected) и города.
*   **Умная обработка прав:** Автоматический запрос пароля (через `pkexec`) только когда это необходимо.
*   **Безопасный выход:** При закрытии приложения предлагает отключить VPN (процесс отключения продолжается в фоне даже после закрытия окна).
*   **Защита от зависаний:** Асинхронное выполнение команд не блокирует интерфейс.

##  Требования

Для работы приложения необходимы:
1.  **Linux** (тестировалось на Ubuntu/Debian/Alt Linux, должно работать на всех дистрибутивах с X11/Wayland).
2.  **Python 3.6+**.
3.  **AdGuard VPN CLI** (установленный и настроенный).
4.  Библиотека **PyQt5**.

##  Установка

### Установка AdGuard VPN CLI
Если у вас еще не установлен CLI клиент, выполните команду:
```bash
curl -s https://raw.githubusercontent.com/AdGuardTeam/AdGuardVPNCLI/master/scripts/install.sh | sh
```

### Установка зависимостей (PyQt5)

**Ubuntu / Debian / Linux Mint:**
```bash
sudo apt-get update
sudo apt-get install python3-pyqt5
```

**Fedora:**
```bash
sudo dnf install python3-qt5
```

**Alt Linux:**
```bash
sudo apt-get install python3-module-PyQt5
```

### Установка скрипта (Рекомендуемый способ)
Не рекомендуется хранить скрипт просто в домашней папке. Лучше разместить его в системной директории для пользовательских программ (`/usr/local/bin`).

1.  Скачайте скрипт:
    ```bash
    wget https://raw.githubusercontent.com/your-username/repo/main/adguard-vpn-gui.py
    ```
2.  Переместите его в системную папку и сделайте исполняемым (мы уберем расширение .py для удобства):
    ```bash
    sudo mv adguard-vpn-gui.py /usr/local/bin/adguard-vpn-gui
    sudo chmod +x /usr/local/bin/adguard-vpn-gui
    ```

Теперь вы можете запускать программу командой `adguard-vpn-gui` из любого терминала.

## Создание ярлыка в меню приложений

Чтобы запускать VPN как обычную программу из меню "Пуск" или с рабочего стола, создайте `.desktop` файл.

1.  Создайте файл ярлыка:
    ```bash
    nano ~/.local/share/applications/adguard-vpn.desktop
    ```

2.  Вставьте туда следующий текст:
    ```ini
    [Desktop Entry]
    Name=AdGuard VPN
    Comment=GUI for AdGuard VPN CLI
    Exec=/usr/local/bin/adguard-vpn-gui
    Icon=network-vpn
    Terminal=false
    Type=Application
    Categories=Network;Settings;
    ```
    *Примечание: Если у вас есть красивая иконка AdGuard, вы можете указать путь к ней в строке `Icon=/path/to/icon.png`.*

3.  Сохраните файл (`Ctrl+O`, `Enter`) и выйдите (`Ctrl+X`).

Теперь "AdGuard VPN" появится в вашем меню приложений.

## Использование

1.  **Первый запуск:**
    Запустите программу. Если вы не авторизованы, нажмите кнопку **"🔐 Требуется вход"**. Выполните указанную команду в терминале для логина.

2.  **Подключение:**
    *   Выберите страну/город из выпадающего списка.
    *   Нажмите **"Подключить"**.
    *   Введите пароль администратора (root) в системном окне.

3.  **Отключение:**
    *   Нажмите **"Отключить"** или просто закройте программу.
    *   При закрытии окна программа спросит, нужно ли разорвать соединение.

## Решение проблем

**Кнопка "Подключить" не активна:**
Убедитесь, что список локаций загрузился. Если нет — проверьте интернет.

**Окно пароля не появляется:**
Программа использует системный `pkexec`. Убедитесь, что у вас установлен пакет `polkit` (есть в 99% дистрибутивов).
